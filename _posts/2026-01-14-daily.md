title: 実装は同時に1つしかできないけど、計画は並行でできるかも
date: 2026-01-14 19:30:00 +0900
---

実装を並行してやるのは自分自身の認知負荷的に難しい。動作確認環境構築が煩雑になるので難しいという理由もあるし、claude code の設定の都合上 git worktree だとうまくいかなくて環境がバラけてしまうという理由もある。

今日は違うやり方を試していた。

(1)まず開発タスクについて Devin と壁打ちを開始して、GitHub で Issue にする。場合によっては 1 つの Issue のときもあるし、複数の Issue に分割するときもある。

(2)それを Devin に、この Issue を実装・対応してという指示で実装をして draft の Pull request としてあげてもらう。

(3)ローカルの開発環境でその draft PR を checkout して、claude code で細部をつめていく。

こうすると、(3)は同時に 1 つしかできないが、(1)(2)は同時並行でいくつもできることに気づいた。あくまで私の認知・集中の都合上これがうまくいきそうというだけだが。
