## 問題

claude-memは現時点でversion 9.0.9が出ていて、重大な問題が修正されているが、直接更新しようとしてもうまくいかなかった。
2週間前の古い9.0.5が最新といわれてしまう。

```
➜  ~ claude plugin update claude-mem@thedotmack
Checking for updates for plugin "claude-mem@thedotmack" at user scope…
✔ claude-mem is already at the latest version (9.0.5).
```

## 解決策

まずmarketplaceを更新してからアップデートしたらいけた。

```
➜  ~ claude plugin marketplace update thedotmack
Updating marketplace: thedotmack...
Updating existing marketplace cache…
✔ Successfully updated marketplace: thedotmack
➜  ~ claude plugin update claude-mem@thedotmack
Checking for updates for plugin "claude-mem@thedotmack" at user scope…
✔ Plugin "claude-mem" updated from 9.0.5 to 9.0.9 for scope user. Restart to apply changes.
```

なお一括でアップデートもいける（が、一応個別に確認することを推奨）

```
➜  ~ claude plugin marketplace update
Updating 3 marketplace(s)...
✔ Successfully updated 3 marketplace(s)
```
