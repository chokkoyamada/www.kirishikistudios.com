Figma の MCP Server が話題なので、実用に向けてのイメージをつかめる程度には知っときたいと思って使ってみた。

[GLips/Figma-Context-MCP: MCP server to provide Figma layout information to AI coding agents like Cursor](https://github.com/GLips/Figma-Context-MCP)

MCP Server の設定は以下。
`npx` で起動するのはセキュリティ的に問題があると実感し始めたけど今回は検証なので許容する。

```json
{
  "mcpServers": {
    "Framelink Figma MCP": {
      "command": "npx",
      "args": [
        "-y",
        "figma-developer-mcp",
        "--figma-api-key=YOUR-KEY",
        "--stdio"
      ]
    }
  }
}
```

アクセストークンの取得の仕方は以下に書いてある。

[Manage personal access tokens – Figma Learn - Help Center](https://help.figma.com/hc/en-us/articles/8085703771159-Manage-personal-access-tokens)

検証に使える自分の Figma デザインは持ってないので、フリーのデザインを使わせてもらった。

今回使ったのはこれ。

[https://www.figma.com/community/file/1212997233512196965](https://www.figma.com/community/file/1212997233512196965)

MCP Client 側は Roo Code。

まずヘッダ部分だけ実装してみてもらった。このようにスコープが小さいとけっこう意図通りにやってくれる。
出力が長いけど、作業過程がわかって興味深いので全部貼っておく(途中出力に含まれるクレデンシャル・ローカルのファイルパスなどは手動で消してある)

