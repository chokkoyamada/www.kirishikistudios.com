# 職務経歴書

## 職務経歴概要

インフラ・サーバーサイドに強みを持つウェブ系のソフトウェアエンジニアです。
設計・コーディング両方を行いつつ、多くの場面でインフラ担当（SRE, DevOps）を兼任し、ソーシャルゲームのサーバーや、インターネット広告配信サーバー、ドローンの IoT システム等の開発と運用を通して、高スループット・低レイテンシ・高可用性が求められるシステムを多数経験してきました。
短いスケジュール・少人数のプロジェクトにおいても安定してサービスを稼働・成長させるための設計・チューニング・自動化などのエンジニアリング業務を得意としています。

その一方で、職場やチームの中で必要とされるポジションを積極的に担当してきました。プロジェクトマネージャ、ディレクター、プロダクトの開発リーダー、フロントエンドエンジニアなどを務めてきて、その時々でピンポイントで足りていないリソースを埋めることも多く経験しています。

## 技術・スキル

### エンジニアリング

サーバーサイドの領域では、Python, PHP, Ruby, Go, Scala, Java, Rust 等のプログラミング言語を用いて、アーキテクチャ設計・コーディング・本番環境の運用まで開発プロセスの広い範囲を担当してきました。
サービス要件に合わせて、Django や Ruby on Rails などのフレームワークを用いて開発したこともあれば、高負荷・複雑な業務要件に対応するためフルスクラッチで開発したこともあります。ゲームエンジンの開発など、基盤ライブラリの開発にも従事したことがあります。

インフラは、オンプレミスでデータセンターをラック借りして Linux(LAMP 環境など)サーバーを構築・運用していましたが、2013 年に AWS を採用し、以後クラウドを中心に利用しています。オンプレミスの OpenStack 環境や GCP 環境でもいくつかの本番環境の運用経験があります。
2017 年からはコンテナ技術に重点を置き、Docker/Kubernetes 関係のインフラの構築・運用に従事してきました。2019 年には CKAD(Certified Kubernetes Application Developer)を取得しました。
現職の株式会社ナイルワークスでは、複数のドローンや基地局などの機材を動的に接続する IoT ネットワークと API サーバーの開発・運用を担当。AWS で構築したインフラを CDK/Cloudformation, Ansible を用いてコードで管理（IaC）しています。

フロントエンドの経験もあり、デザインのスキルはありませんが、デザイナーのヘルプがあればウェブアプリケーションのフロントエンドの実装はできます（React, Vue, jQuery など）

ウェブサービスの運用においては、ビジネス的な観点・エンジニアリング効率化の観点の両面においてデータを収集・活用するための基盤づくりを多く行ってきました。
・複数プロダクトを束ねる DMP(データマネジメントプラットフォーム)の構築
・Prometheus, DataDog などを用いたサーバー監視の仕組みづくり
・NewRelic・Stackdriver(OpenCensus)・JVM の各種ツール等を用いたプロファイリング・分散トレーシングによってサーバーをチューニング

### 農業用自動運転ドローンのサーバー・インフラの開発・運用

【概要】サーバーエンジニアとして、ドローンの製造保守・飛行のための IoT ネットワークおよび API サーバーの開発・運用を行っている。ドローンという飛行する物体を扱うため、高可用性・高信頼性を第一にしつつ、少ない人数で保守・発展させていくための開発に従事。
【プロジェクト人数】サーバー・インフラエンジニアは 2 名（自分がそのうちの 1 名）、その他ファームウェア・ハードウェア・電子機器のエンジニア等を含めて 15 人程度の開発チーム
【開発規模】開発フェーズ:2 人/月程度、運用フェーズ:2 人/月程度

・IoT ネットワーク
管理している ドローンおよび基地局などの関連機材を動的に接続する IoT ネットワークを OSS の VPN ソフトウェア(SoftEther)を用いて構築。
インフラは AWS で、EC2、S3、Cloudwatch などが中心のシステム。Cloudformation と Ansible で構成管理している。AWS の Availability Zone 別のコールドスタンバイという形での冗長構成を組んでいる。

別システムで、AWS IoT Core を用いた MQTT プロトコルによる IoT ネットワークも構築・運用している

・API サーバー
ドローンなどの機材やユーザーが利用する API サーバー(REST/GraphQL)を開発・運用。
API の役割は機材の認証認可・機材間のペアリング・IoT ネットワークへの接続管理・人間のユーザーアカウントの認証認可・組織や農場や飛行経路の情報の入出力など。
ALB \+ ECS(Fargate) \+ RDS(Postgresql)が中心のシステム。開発言語は Python(Django)。
Django 組み込みのテストフレームワークを用いた API の自動テストを推進している。
直近ではセッション認証および OAuth2.0 による認証認可両方に対応し、認証認可サーバーと API サーバー本体を分離し、認証認可の仕組みを拡張して関連するウェブサービスを多数立ち上げている。

・ログ集計/解析
機材からクラウドにログがアップロードされ次第、イベント駆動で解析して即座にウェブの管理ツールで表示できるシステムを構築した。

・運航監視システム
機材からリアルタイムでクラウドに向けて送信される位置・姿勢・機材のバッテリー残量・電圧等の情報をリアルタイムで観察できるウェブシステムのバックエンド・フロントエンドを開発した。

・機材管理システム
機材をシリアル番号を軸に情報を集約し、製造・輸送・試験結果・社内スタッフによるコメント等を入力・管理できるウェブシステムのバックエンド・フロントエンドを開発した。
